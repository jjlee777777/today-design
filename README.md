# TODAY DESIGN GitHub Pages 버전

## 폴더 구성

```text
today-design-github/
├─ index.html
├─ css/
│  └─ style.css
├─ js/
│  └─ main.js
├─ images/
│  ├─ favicon.svg
│  └─ og-image.svg
├─ .nojekyll
└─ README.md
```

## GitHub Pages 업로드 방법

1. GitHub에서 새 저장소를 만듭니다.
   - 저장소 이름 추천: `today-design`
   - Public 선택

2. 이 폴더 안의 파일을 전부 업로드합니다.
   - 폴더 자체가 아니라 `index.html`, `css`, `js`, `images`가 저장소 첫 화면에 보여야 합니다.

3. 저장소에서 아래 메뉴로 이동합니다.
   - Settings
   - Pages
   - Build and deployment
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save

4. 배포 주소 예시
   - `https://jjlee777777.github.io/today-design/`
